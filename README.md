# StudyForge

Free, open-source study helper that turns notes and PDFs into quizzes and flashcards. Self-hostable.

## Features (v0.1 plan)
- Upload a PDF or paste notes
- Generate quiz questions with Claude
- Flip-card study mode
- Export to CSV (Anki-compatible)

## Setup
1. Clone the repo
2. Install: `pip install -r requirements.txt`
3. Add your Claude API key to a `.env` file: `ANTHROPIC_API_KEY=your_key_here`
4. Run: `streamlit run app.py`
